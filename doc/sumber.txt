NAME
  sumber - print a statistical summary of input numbers

SYNOPSIS
  sumber

DESCRIPTION
  Read space-separated numbers then print the following statistics with up to 10
  significant digits:

    Count
    Sum
    Minimum
    Maximum
    Range
    Mid-Range
    First Quartile
    Second Quartile
    Third Quartile
    Interquartile Range
    Mid-Hinge
    Arithmetic Mean
    Geometric Mean
    Standard Deviation
    Skewness
    Kurtosis

EXIT STATUS
  1 if allocating memory fails;
  2 if reallocating memory fails;
  3 if less than 2 numbers are read;
  0 otherwise;
